# Architecture Decision Record: Unified Multi-Task Model vs Modular Standalone Models

**Date**: September 2026  
**Status**: APPROVED / IN PRODUCTION  
**Context**: OmniFace AI Biometric Inference Architecture  

---

## 1. Problem Statement & Audit Findings

During the empirical biometric quality audit (`OMNIFACE_ML_QUALITY_AUDIT.md`), the 282 MB `unified_omniface.tflite` model was evaluated. The audit revealed the following critical defect:
- The unified multi-task graph merger was generated by combining 8 distinct neural architectures (MiniFASNet, CavaFace, FaceNet-512, FaceMap 3DMM, FaceAttribNet, EyeGaze, MediaPipe Face Mesh, HRNet) using random weight initialization.
- The actual trained weights from upstream checkpoints and Qualcomm AI Hub artifacts were **not transferred into the merged graph**.
- Consequently, all output tensors produced by `unified_omniface.tflite` (including the 512-D identity embedding and anti-spoof logits) consisted of pseudo-random floating-point noise.
- Despite this, whenever `unified_omniface.tflite` was present on device storage, `UnifiedFaceIntelligenceEngine.isModelLoaded` evaluated to `true`, silently hijacking the inference pipeline and bypassing genuine trained models.

---

## 2. Decision

**OmniFace AI deprecates `unified_omniface.tflite` from production use.**

In its place, OmniFace AI establishes the **Verified Modular Standalone Engine Pipeline** as the sovereign, production-authoritative architecture:
1. **Identity Biometrics**:
   - Primary: `mobilefacenet_512d_int8.tflite` (1.54 MB Per-Channel Quantized INT8 for NPU/NNAPI, sub-8ms latency).
   - High-Security / Flagship: `cavaface.tflite` (250 MB ArcFace 65.5M param model for high-assurance access).
   - Fallback: `mobilefacenet_512d_fp32.tflite` (4.85 MB multi-core CPU XNNPACK).
2. **Passive Anti-Spoofing (PAD)**:
   - `silentface.tflite` (MiniFASNetV2, NCHW [1, 3, 80, 80], BGR channel ordering).
3. **Physical 3D Topography**:
   - `facemap_3dmm.tflite` (21 MB 3D Morphable Model for true facial depth variance).
4. **Subpixel Auxiliary Gaze & Mesh**:
   - `eyegaze.tflite` (9.7 MB pupil tracking) & `face_landmark_detector.tflite` (2.4 MB 468-point mesh).

---

## 3. Engineering Rationale

| Dimension | Unified Multi-Task Model (`unified_omniface.tflite`) | Verified Modular Pipeline (Production) |
| :--- | :--- | :--- |
| **Weight Integrity** | ❌ Random weights (audit proved 0% accuracy) | ✅ 100% verified trained weights from official checkpoints |
| **Memory Footprint** | ❌ 282 MB continuously mapped in RAM | ✅ 1.54 MB baseline; auxiliary models loaded dynamically on demand |
| **Hardware Delegation** | ❌ All subgraphs tied to a single delegate (fails if any operator unsupported) | ✅ Heterogeneous execution: NPU for ArcFace, GPU for PAD, CPU for 3DMM |
| **Thermal Scaling** | ❌ Monolithic execution induces severe thermal throttling | ✅ Granular throttling: auxiliary models shed during WARM/CRITICAL states |
| **Fault Isolation** | ❌ Single failure crashes entire verification pipeline | ✅ Isolated failure handling with graceful fallbacks |

---

## 4. Safety Guardrail & Invariant

`UnifiedFaceIntelligenceEngine` is guarded with `ALLOW_UNVERIFIED_UNIFIED_ENGINE = false`.
In production builds, `UnifiedFaceIntelligenceEngine` will refuse to initialize unverified merged flatbuffers, guaranteeing that OmniFace AI always routes through verified, trained standalone models.
